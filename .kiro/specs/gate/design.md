# Design: the Gate

DRAFT for owner review. Details and evidence: `SPEC_GATE_v2.md`, `docs/reports/VERIFICATION_REPORT.md`, `docs/reports/EXECUTOR_REPORT.md`, `docs/reports/STRANDS_REPORT.md`, `docs/reports/BACKEND_REPORT.md`, `docs/ui-v2/UI_BUILD_REPORT.md`. Diagram: `docs/architecture/architecture.html`.

## Architecture

```
Browser UI (Vite+React) --HTTP+SSE--> FastAPI (server/) --chat turn--> Strands Agent (agent/)
                                          |                               | 5 @tool wrappers
                                          | POST /mfa (source=human)      v
                                          +---------------------------> Gate (bank/gate.py) --ACCEPT only--> stub real tools (bank/real_tools.py)
Agent -> BeforeToolCallEvent hook -> Gate.peek (read-only, cancel_tool on reject)     |
JFLAP 7.1 (build time) -> finance.jff -> export-table -> scripts/gen_executor_table.py -> bank/executor_table.py (lookup)
Agent -> Amazon Bedrock (Nova 2 Lite in use; Claude Haiku blocked by the use-case form)
```

## Components
- **Policy** `policy/finance_table.json` (data), `policy/finance.jff` (generated by `scripts/gen_jff.py`), second independent model `finance_flags.jff`.
- **Generator** `scripts/gen_executor_table.py` reads JFLAP `export-table` output, writes `bank/executor_table.py` (live cells only; missing cell = reject). `--check` for staleness.
- **Gate** `bank/gate.py`: `run(symbol, args, source='llm')`, `peek`, read-only `state`, one lock, private `_state` written only in `__init__` and `_commit`. Guard (`bank/guard.py`) runs after the table accepts.
- **Agent** `agent/`: five wrappers, `SequentialToolExecutor`, hook calls `gate.peek` and sets `event.cancel_tool` on reject or on any hook error.
- **Server** `server/`: sessions, SSE events (`tool_proposed`, `gate_verdict`, `state_change`, ...), `GET /policy`, `POST /session/{id}/mfa`, static UI mount.
- **UI** `ui/`: automaton, chat, proof inspector, human approval. Final visual style undecided (Dark Panel comp D is the leading candidate); the design here does not depend on it.

## State machine
5 states, 6 symbols (A D E M T C), 30 cells. Accepted language in `SPEC_GATE_v2.md` 4.4. A rejected proposal does not move the session.

## Error handling
Fail closed everywhere: any exception becomes a reject with no state change. Strands aborts an invocation if a hook raises, so the hook catches and cancels.

## Testing strategy
Stub `Model` (`tests/stubmodel.py`) for the agent loop; no Bedrock in automated tests. One real adversarial run (Nova 2 Lite) is recorded in `docs/reports/STRANDS_REPORT.md`.
