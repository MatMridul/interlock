# DEPTH REPORT: product depth and polish

Branch `product-depth` (worktree `C:\Mridul\Programs\Kiroween-wt\depth`), from `origin/sync-main` e8d5180. Nothing pushed or merged. 0 real Bedrock calls (server ran with `INTERLOCK_MODEL=off`).

## Built, per task id

- **C1 You are the agent.** `server/manual.py` (new): `GET /config` returns `{"model":"on|off"}`; `POST /session/{sid}/propose` takes 1 to 8 actions (the five agent tools, plus `mfa_tool` as a refused attempt), runs each through `gate.run(source="llm")` and streams the same SSE events as chat. There is no source field, so the human step cannot be spoofed. `INTERLOCK_MODEL=off` makes sessions model-less, `/chat` answers 403, and the UI defaults to `Agent: you`. Header switch `Agent: model | you`. Attack vectors and legit moves become fixed proposal scripts in `ui/src/lib/scripted.ts`, labelled `scripted`. app.py gained 4 lines, session.py 3 (model None means no agent).
- **C3 Why was this blocked.** `ui/src/lib/why.ts`: BFS over the `/policy` table. On every agent block: dashed ghost path on the stage, a caption on the stage, the same sentence in the toast and in the Proof drawer ("TRANSFER needs MFA first: DRAFTED is open, a human must approve."), "never allowed from here" when no path exists. Tie-break is table order (APPROVED + DRAFT gives TRANSFER, not CANCEL).
- **C4 What if.** `WhatIfBox` in the Proof drawer, words or letters, ACCEPT or REJECT, first failing step, client-side only. Test reads the 21 traces from `docs/reports/VERIFICATION_REPORT.md` and checks all 21.
- **C5 Replay.** Tape scrubber (range input, arrow keys), stage shows that state with a `REPLAY` tag, `Share replay` copies `#replay=v1.<letters>`. A link is validated against `/policy` (letters, length 1 to 64, every step live) and loads read-only without creating a session; a bad link is rejected with a toast.
- **C6 Audit export.** `Export audit log (JSON lines)` in the drawer; schema in `docs/AUDIT_FORMAT.md`.
- **Polish.** a) stage min 640x320 enforced by clamping panels, stage text floor 10 px (measured), tape collapsible to one line, empty rail collapses to 0. b) ledger row for the last transition re-glows, blocked cell shown as `δ(DRAFTED, TRANSFER) = undefined` in red. c) verdict chips open receipts (state, symbol, table cell, latency, engine, layer as sent; timestamp is the browser clock, labelled). d) hover or focus a state lists its allowed symbols; hover a tape cell re-traces its edge. e) counters roll for 0.4 s, none under reduced motion. f) `NO SIGNAL from gate. Retry.` fault panel. g) one aria-live line per event, assertive for blocked and needs-human (errors are also assertive, see weak spots). h) at 900 px and under: console is a bottom sheet with a handle, stage first, tape collapsible, secondary header buttons hidden.

## Five weakest things

1. In you mode the console's log area is short when the you-panel is shown, so an open receipt scrolls inside it (visible in `1440-receipt.png`).
2. At 1440x900 the stage is only 423 px tall with the default tape; labels are 10 px, readable but small.
3. Scripted vectors run from whatever state the session is in, so "Double spend" and "Skip MFA" are only dramatic from the right state.
4. Error toasts are still assertive (the brief says only blocked and needs-human); the notification test model was left alone.
5. A shared replay needs `GET /policy` from the server, so it is not usable fully offline, and the receipt timestamp is the browser clock, not a server time.
